# Site registry

It exists so the same site is never built twice. Before each storyboard, reread the last three entries. The new site reuses neither their signature move, nor their font trio, nor their easing family, unless the light calls for it; in that case, say so.

This example file is published. The real registry (`registry.md`) stays local and is not versioned, because it names clients. If it does not exist, copy this file to `registry.md`.

Add an entry with the same format after each delivery.

---

## 01 · Notary office in Cannes (2026-10)

- **Mode:** redesign, home page only. Content reused word for word.
- **User verdict:** "magnificent".
- **Light:** Cannes light (sunset over the bay, ochre façades, shutters, palm shadows).
- **Media:** Pexels. Video 18682385 (sunset seen from a balcony), video 26508527 (palm shadow), and 10 photos.
- **Voices:** Instrument Serif (display), Inter Tight (workhorse), Geist Mono (mono).
- **Palette:** paper `#ece8e1`, ink `#161512`, night `#131210`; the photo brings the colour.
- **Easing:** expo (`expo.out`, `expo.inOut`).
- **Sequence:**
  1. Intro that becomes the hero, then edge-to-edge wordmark (01 + 02).
  2. Curtain over the hero, then scroll highlight with inline media (03 + 04).
  3. Row reveal, then shared element (05 + 06).
  4. Media expand that pushes the sentence aside (07).
  5. Horizontal scroll of the reviews (08).
  6. Footer reveal (11); morphing nav (09); "Appointment" overlay (10); live status (12); mobile action bar (13).
- **Signature moves:** the image window that becomes the full-screen video; the thumbnail that becomes the practice-area page.
- **Pins:** 2 (media expand, reviews).
