# Changelog

All notable changes to UI Blueprint are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-10-15

First public release.

### Added
- Two entry points: redesign from a URL (with an optional recommendation prompt), and creation from a direction-and-theme prompt.
- The method in eight steps and the six principles (`SKILL.md`).
- References:
  - content natures and their candidate recipes;
  - montage rules;
  - motion and type grammar;
  - visitor guardrails;
  - media sourcing;
  - technical pitfalls;
  - motion vocabulary.
- 13 validated recipe cards: intro to hero, edge-to-edge wordmark, curtain over hero, scroll highlight with inline media, row reveal, shared element transition, media expand, pinned horizontal scroll, morphing nav, overlay with label, footer reveal, live opening status, and pill buttons with a mobile action bar.
- About 20 drafted recipes awaiting validation (`references/recipes/_drafts.md`).
- `scripts/capture.js`: frame-by-frame QA contact sheets (intro, scroll states, click sequences, desktop and mobile).
- `scripts/contact-sheet.js`: Pexels contact sheet and video file lookup.
- `registry.example.md`: template for the anti-repetition registry.
